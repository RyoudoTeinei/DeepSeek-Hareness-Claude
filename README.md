# DeepSeek Hareness Claude

在 DeepSeek Harness（DSH）里使用服务器上的 Claude Code。插件通过 SSH 连接远程工作区，把对话、终端和文件同步放在同一个本地项目里。

## 功能

| 功能 | 用法 |
| --- | --- |
| 工作区接入 | 使用 DSH 原生工作区列表。鼠标移到项目上，点插头图标打开接入面板。已保存接入配置的项目会显示同步状态，点击标签可直达文件同步。 |
| Claude Code 对话 | 点「接入 Claude」，在 DSH 的模型选择器选「Claude Code · 远程工作区」，即可发送文字和查看回复。 |
| 远程终端 | 打开「服务器终端」使用远程 Shell，也可在 Claude 终端中运行斜杠命令和处理权限提示。重新接入会接管同一个 tmux 会话，保留远程进程与对话。 |
| 双向自动同步 | 两端保存的文件变更会自动同步。同步终端显示扫描、当前文件、进度和执行结果。运行中的任务可以暂停或恢复。 |
| 差异处理 | 使用 Git 风格的彩色差异检查改动。可以逐项或批量选择保留本地或服务器版本。写入前核对文件版本，并备份被替换的内容。 |
| 图片与额度 | 将剪贴板图片上传到远端并插入路径。在「Claude 额度」查看 Claude Code 报告的 5 小时和每周剩余额度、重置时间及更新时间。 |

## 安装与接入

- 本机使用 Windows 版 DSH，并安装 Node.js、Git、OpenSSH 和 Python 3.10 或以上版本。
- Linux 服务器需安装 Git、Python 3.10 或以上版本、tmux 和 Claude Code。先在服务器上完成 Claude Code 登录，并确认本机能用密钥登录 SSH。
- 在 DSH 插件管理器添加此 GitHub 仓库并启用。插件默认使用桌面 profile，其他 profile 需要在 `client.js` 中调整插件路径。

1. 在 DSH 添加或打开本地项目。将鼠标移到项目上，点插头图标。
2. 填写 SSH 主机（例如 `user@host` 或 SSH 别名）和远程目录名。使用默认 SSH 配置时，可留空私钥路径。
3. 点「接入 Claude」进入会话，或点「文件同步」配置该项目的同步任务。远程项目位于 SSH 用户目录的 `~/projects/` 下。

## 文件同步

- **首次开启**。远端目录不存在时，界面会请你确认创建。远端目录为空时，可直接确认同步。已有文件时，先查看差异再确认开启。
- **查看与处理差异**。点「有差异」查看文件。运行期间可以阅读差异。要应用保留版本的选择，先暂停任务。内容冲突会保留两端版本，只有换行不同的文件会单独识别。
- **规则与备份**。在「同步设置」编辑后缀、忽略规则、大小上限和备份策略。自动同步读取项目的 `.gitignore`、相关 `.gitattributes` 属性及 `.editorconfig` 换行规则。默认限制为代码和文档 10 MiB、图片和 PDF 25 MiB、其他文件 100 MiB。权重、视频和压缩包默认忽略。
- **状态保存**。两端项目的 `.dsh-sync/` 保存基线、日志和备份，并从文件同步中排除。关闭面板后任务继续运行，DSH 重启时会恢复之前开启且未暂停的任务。
- **兼容模式**。手动 Git 推送、快进拉取和 Mutagen 同步收在「旧版同步」里。只有兼容模式需要另装 Mutagen。同一个项目切换到自动同步前，先暂停旧版任务。

自动同步处理工作目录文件，两端 Git 历史各自维护。空目录、重命名识别、符号链接复制和完整 ACL 同步目前尚未支持。

## 开发验证

```bash
npm test
```

测试覆盖 JavaScript 语法、同步设置、回复读取和 Git 推送保护。自动同步的初始化、冲突保护、批量处理及暂停流程也已在 Windows 与 Linux 之间的独立 SSH 目录中验证。
